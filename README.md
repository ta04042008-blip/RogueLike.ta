# ローグライク・カード

ブラウザで遊べる、デッキ構築型のローグライクカードゲームです。

`index.html` をブラウザで開くだけで遊べます(ビルド不要)。

## ルール
- 全12階層。各階層で進む道(戦闘 / 強敵 / 休憩所 / イベント)を選び、最後は魔王と戦います。
- 毎ターンエネルギー3、手札5枚。カードをクリックして使い、攻撃対象が複数いる場合は敵をクリックします。
- 敵の頭上には次の行動(意図)が表示されます。
- 戦闘に勝つとカードを1枚獲得(スキップ可)。休憩所ではHP回復かカード削除ができます。
- 状態異常: 脆弱(受けるダメージ1.5倍)/弱体(与えるダメージ0.75倍)/筋力(与ダメージ加算)。

## カードの追加
`index.html` の `CARDS` に定義を足すだけで追加できます。
